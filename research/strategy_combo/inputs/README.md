## 2. 重建方法

1. 讀取 TEJ 全部納入／剔除事件，依事件日排序；同一天先納入、後剔除。
2. 只套用 TEJ 時，最終名單與 2026-11-17 元大 50 檔完全一致，但 2014-01-01 只有 47 檔。原因與補法見第 3 節。
3. 2014 年以後，用 TIP 官方通知補正 TEJ 的缺漏與錯誤日期（見第 4 節），不以維基為準。
4. 在 2014-01-01 把 TEJ 缺少、但已確認當時在指數內的 3 檔補進去，再往後套用補正後的事件。
5. 區間採左閉右開：`start_date` 是納入生效日（當日起為成分股），`end_date` 是剔除生效日（當日起不再是成分股）。仍在指數內者 `end_date` 留空。
6. 無成員異動的季審生效日不另列在 `membership_by_effective_date.csv`（成員與前一次相同）。例如 2014-03、2014-09 官方定審為「納入無、刪除無」。
7. 2014 年以前的完整歷史**未**用官方檔逐則追溯，本表不宣稱 2002–2013 年名單完整。

名稱處理：TEJ 名稱末尾的 `*`（如 國巨*、康霈*）已去掉。2887 在 2025-07-14 因合併新光金，名稱由台新金改為台新新光金（見第 4 節）；`membership_intervals.csv` 寫「台新金／台新新光金」。

## 3. 為什麼 TEJ 推到 2014-01-01 只有 47 檔

不是 2014 年以後少了 3 次配對的納入，而是 **TEJ 這份「特殊事件日期」從頭就漏了若干股票的納入／剔除**，其中有些是後來下市或合併換代碼的公司。

- 2002-04-30（指數基期）TEJ 只有 42 筆納入，不是 50 檔。2002-10-29 證交所公布的原始 50 檔（大紀元轉述中央社）裡，至少「日月光、矽品」未出現在 TEJ 任何一筆事件中。2002–2013 年還有其他缺漏（例如華映、華亞科較早的進出），本次**未完整追溯**，標未確認。
- 只套用 TEJ 時，檔數在 2012-06-18 至 2018-04-17 之間一直是 47。2014-01-01 的 47 檔，就是少了下面 3 檔：

| 代碼 | 名稱 | 2014-01-01 的狀態 | 依據 |
| --- | --- | --- | --- |
| 2311 | 日月光 | 已在指數內 | 2002 年原始名單含日月光；TEJ 全程無紀錄；TIP 2018-04-13 通知仍寫「維持在臺灣50」。真正首次納入日未完整追溯，區間 `start_date` 用 2014-01-01。 |
| 2325 | 矽品 | 已在指數內 | 2002 年原始名單含矽品；TEJ 全程無紀錄；TIP 2018-04-13 通知將其自臺灣50刪除，可反推此前在指數內。真正首次納入日未完整追溯，區間 `start_date` 用 2014-01-01。 |
| 3697 | F-晨星 | 已在指數內 | TIP TechnicalNotices/213、/34：2014-01-16 因與聯發科合併自臺灣50刪除。若當時不在指數內，不會有這則刪除。真正納入日未確認（未下載 2012 年定審檔），區間 `start_date` 用 2014-01-01。 |

這 3 檔在 2014 年以後的去向，對得上 TEJ 那些「只納入不剔除」或「只剔除不納入」的日期（見下一節）。補上之後，2014-01-01 起除兩段官方延期外，檔數都是 50，最終名單仍與元大 50 檔一致。

## 5. 驗證結果

- 補正後，2014-01-01 為 50 檔（含 2311、2325、3697，不含尚未納入的 3474）。
- 已核對的官方案例與本表一致：2014-01-16 華亞科／晨星、2015-09-21 儒鴻／宏達電、2016-11-30 中壽／華亞科、2018-04-18 國巨／矽品、2018-04-30 3711 接續 2311、2019-09-23 新光金／友達、2020-09-21 瑞昱與矽力-KY／中壽與新光金、2024-03-18 世芯-KY／豐泰、2026-09-21 藥華藥／世芯-KY。
- 最終（2026-09-21 起至資料截止日）50 檔代碼與元大 2026-11-17 名單完全一致。
- 每月月底檔數：2014-01 至 2026-11 共 155 個月，**只有 2026-03 月底是 49 檔**（欣興延期，3/31 仍未納入）。2025-12-31 當日南亞科已生效，故 12 月底是 50 檔。2026-11 尚未到月底，`month_end_snapshot.csv` 的 2026-11 是 2026-11-17 的名單，仍是 50 檔。
- 補正後沒有「重複納入」或「無納入卻剔除」的異常。

## 8. 尚未解決的缺口

1. **2014 年以前未完整追溯。** 2311、2325、3697 在 2014-01-01 之前何時納入，以及 2002–2013 年 TEJ 還漏了哪些股票（檔數曾長期低於 50），本次未用 TIP 逐則核對。若策略需要 2014 年以前的名單，要另做。
2. **2311 → 3711 的代碼切換日。** 採用 2018-04-30（掛牌日／TEJ 3711 納入日／公司治理100 通知），但未找到臺灣50專文。2018-04-18 至 04-29 本表仍列 2311（官方說維持在指數內，且該段停止買賣）。
3. **不定期異動的完備性。** 2014 年以後造成檔數不平衡的 TEJ 事件，已能用上述官方通知全部解釋，且最終名單與今日錨點一致。但不能排除還有「一進一出、TEJ 與官方都漏了」的情況；若有，本表會在該段同時少一檔、多一檔。目前沒有這種跡象。
4. **3697 的納入日**標未確認。
5. **2888、2823 下市後的股價**不在回測需要範圍內（剔除日之後不必補）。
