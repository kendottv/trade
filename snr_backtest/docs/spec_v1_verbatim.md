### Status
READY_FOR_APPROVAL

### Version
持股熱力圖 v1（獨立於 NN 修正 v5）

### Problem
讓使用者直觀看懂兩個帳戶的持股配置，以及當日漲跌與買入後損益。

### Current behavior
[現有持股介面](https://github.com/kendottv/trade/blob/main/snr_backtest/web/app.js)兩邊都是表格。紙上帳戶已有市值、產業、損益；永豐模擬帳戶使用快照，有市值與損益，但缺產業。兩邊都未提供持股今日漲跌欄位，須補上唯讀報價資料。

### Target behavior
兩個帳戶各自顯示熱力圖，預設「今日漲跌」，可切換「買入後損益」，也可切回原表格。

每格一檔股票，面積依持股市值、按產業分組；紅漲綠跌、零值中性色。格內顯示名稱與所選百分比，點選可看完整資訊。配置比例統一表示「占該帳戶持股總市值」，不含現金。

### Acceptance criteria
- **AC-1** 兩帳戶各自顯示所有持股，包含模擬帳戶舊持股及其原有標示；不得混合帳戶資料。
- **AC-2** 兩邊皆能切換熱力圖／原表格，原表格欄位保留；預設熱力圖及今日漲跌模式。
- **AC-3** 有效市值方塊依市值比例配置面積，扣除標題、間距後面積占比與市值占比差距不超過 1 個百分點。切換顏色模式不改面積或排列；現金不入圖。市值無效或非正值者列在獨立「無法配置面積」清單，不捏造面積、不漏掉持股。
- **AC-4** 同產業歸同組，缺產業歸「未知」。紙上使用既有產業；模擬依股票代號對照最新目標檔產業，找不到即歸未知，不猜測。
- **AC-5** 今日漲跌＝同筆有效報價的現價除以昨收再減一；買入後損益＝帳戶持股現價除以平均成本再減一，不另估費用。正值紅、負值綠、零值中性色；顏色與標示百分比一致。
- **AC-6** 缺報價、昨收無效、平均成本無效或計算失敗時，受影響指標顯示「—」及中性色，不冒充 0%。某檔報價失敗不阻止其他持股顯示。
- **AC-7** 點選任一方塊或缺值清單項目，可讀到代號、名稱、產業、股數、市值、持股內占比及兩種百分比；小方塊文字不得溢出遮擋其他股票。占比只對有效正市值計算；有排除項目時明示比例未含該項目。
- **AC-8** 分別標示持倉快照與當日報價時點，未知即標「時間未知」。模擬快照依既有更新門檻標示過期；非當日報價不得冒稱今日漲跌，改顯示「—」。所有日期以台北時間判斷，頁面不標榜即時行情。
- **AC-9** 空持股顯示「沒有持股」；資料載入失敗與空持股分開顯示，不放假資料。
- **AC-10** 操作熱力圖不寫入帳戶、不觸發送單或新券商登入，不修改 NN v5 的選股、調倉與預測契約。
- **AC-11** PR 附兩帳戶、兩種顏色模式、表格切換的畫面證據，以及用假資料核對面積、缺值、無效成本、空持股、過期資料與帳戶隔離的結果；文件說明公式、占比分母與資料時點。

### Non-goals
不做全市場地圖、播放或國家切換；不改 NN v5；不新增交易或券商登入；不讀取、複製、印出或保存 `.env`、`broker_secrets.json`、任何金鑰，不修改真的 `trades.db`；不合併兩個帳戶；不要求新增完整 UI 測試框架。

### Affected contracts
修改範圍為 `snr_backtest/web/index.html`、`web/app.js`、相關樣式，以及 `webapp.py` 的 `/api/state`、`/api/sim` 顯示資料。

保留原欄位與快照格式；新增顯示用產業、當日漲跌、時點及缺值狀態。使用既有唯讀報價及 `latest_target()` 的產業對照，不修改目標檔或送單程式。持倉市值使用帳戶快照，今日漲跌使用同筆報價，不混用兩個時點計算。
