# breakout_v2 比較報告（OOS 選參）

決策指標是**樣本外（OOS）**，不是樣本內報酬。沒有把拉回策略當主路徑再優化。

## 相對 v1 改了什麼

- **核心不變**：收盤突破前 20 日最高（不含當日）、SNR_20 閘門、停利 +25%／停損 -20%（同根先停損）、連續 3 日收盤跌破前 20 日最低 → 次日開盤出清。成本、1 張、下一根開盤成交都沒改。
- **v2 可選濾網**（由 OOS 網格決定開不開）：
  1. `snr_min`：Kaufman SNR_20 門檻（網格 0.30 / 0.40 / 0.50）
  2. `snr_rising`：SNR_20 > SMA(SNR_20, 5)（趨勢品質在改善）
  3. `vol_mult`：成交量 ≥ vol_mult × 20 日均量（0 = 關；網格另測 1.2）
  4. `twii_filter`：僅在 ^TWII 收盤 > SMA 60 時進場
  5. `no_chase`：收盤 > 前 20 日高 × 1.08 視為追價過遠，跳過
  6. `trail`：未實現（當根最高價相對進場）≥ 12% 後，若收盤跌破前 15 日最低 → 次日開盤出（硬停利停損仍在）
- 網格是**縮小版** 3×2×2×2 = 24 組（snr_rising / trail 預設關），再只對 OOS 前 5 名加測 rising / trail。不是 160 組全搜，故意避免在 2021–2026 半導體大多頭上曲線擬合。

## 含世紀 vs 不含世紀

- v2 全樣本 **含世紀**：報酬 235.8%，勝率 68.7%，131 筆。
- v2 全樣本 **不含世紀**：報酬 181.9%，勝率 68.2%，期望值 10.7%，PF 3.32，回撤 -12.5%，110 筆。
- v1 全樣本不含世紀：報酬 284.7%，勝率 69.4%。
- **世紀仍是單檔報酬冠軍**（v2 721%、回撤 -64%；v1 也是 710%）。等權合計會被它拉高：v2 含世紀 235.8% → 不含 181.9%。拿掉之後勝率幾乎不變（68.7% → 68.2%）、期望值仍約 10.7%，所以**不是「只靠世紀才會賺錢」**，但把 721% 那一檔平均進去再對外說「電子股突破策略 CAGR 27%」是誤導。
- 世紀是樂透型飆股。紙上帳戶全倉 1 張、不模擬漲停鎖死，實盤做不到這種報酬路徑。致新在 v2 全樣本是虧的（-5.4%），分檔不是張張賺。

## 誠實的限制

- **2021–2026 台股半導體／AI 鏈是極端大多頭。** OOS（2024-08-13 → 2026-08-13）幾乎整段都還在這波行情裡，**不是**空頭或高利率年份的樣本外。通過本報告的 OOS 門檻，只代表「在多頭後半段沒有立刻壞掉」，不能外推到 2018、2022 那種環境。
- 縮小網格仍有過擬合風險：24 組 + 前 5 名的 extras，等於在同一段行情上試了幾十種濾網。OOS 只有約兩年、成交筆數可能只有幾十，期望值的抽樣誤差很大。
- 選參規則刻意**不最大化 IS 報酬**。若某組 IS 報酬最高但 OOS 勝率／PF 不合格，它不會被選。這降低（但消除不了）曲線擬合。
- 未模擬漲跌停無法成交、未模擬盤中流動性、未加滑價。下一根開盤成交在跳空時會比收盤價更痛。
- 價格走 yfinance `auto_adjust=True`，權息調整後的價格與真實撮合價不會完全一致。
- **這仍是紙上交易。** 沒有實盤成交、沒有心理、沒有部位上限。不要把回測 CAGR 當作出發點。
- 拉回策略（pullback_v1）五年勝率約 40.7%，這次**沒有**再拿它當主路徑調參。

## 建議寫進 config.py 的預設

```python
BREAKOUT_V2_SNR_MIN = 0.40
BREAKOUT_V2_SNR_RISING = False
BREAKOUT_V2_VOL_MULT = 0.0
BREAKOUT_V2_TWII_FILTER = True
BREAKOUT_V2_NO_CHASE = False
BREAKOUT_V2_TRAIL = True
```

跑網格：`/workspace/trade/.venv/bin/python /workspace/trade/tune.py`
跑全樣本（含 v1 / v2）：`/workspace/trade/.venv/bin/python /workspace/trade/run.py`

—— 報告由 `tune.py` 依本次網格數字自動產生，不要手工改結論。
